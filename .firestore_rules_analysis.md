# Legal acceptance rule reasoning

The new owner-only `users/{uid}/legal/{docId}` rule is isolated from the existing user document, planner, financial-entry, wallet, security, and catch-all rules. Creation requires an authenticated owner, an `acceptance_` document ID, exactly the three receipt fields, a server-evaluated request timestamp, and bounded non-empty version strings. Immutable create-only receipts prevent later client mutation or deletion while preserving only owner reads.
